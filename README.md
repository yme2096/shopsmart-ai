# ShopSmart AI

A full-stack MERN Ecommerce web application with authentication, admin dashboard, product management, cart system, image uploads, and online deployment.

---

## 🚀 Live Demo

Frontend: https://shopsmart-ai-drab.vercel.app

Backend API: https://shopsmart-ai-yk2h.onrender.com

---

## 📌 Features

* User Authentication (Login/Register)
* JWT Authentication
* Admin Dashboard
* Add/Edit/Delete Products
* Product Search & Filtering
* Category Filtering
* Shopping Cart
* Razorpay Payment Integration
* Cloudinary Image Upload
* Responsive UI
* MongoDB Atlas Database
* Fully Deployed MERN Stack Application

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yme2096/shopsmart-ai.git
```

---

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

### Backend Setup

```bash
cd backend
npm install
npm start
```

---

## 🔑 Environment Variables

Create `.env` file inside backend folder:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret

RAZORPAY_KEY_ID=your_key
RAZORPAY_SECRET=your_secret

CLOUD_NAME=your_cloudinary_name
CLOUD_API_KEY=your_cloudinary_key
CLOUD_API_SECRET=your_cloudinary_secret

FRONTEND_URL=http://localhost:5173
PORT=5000
```
